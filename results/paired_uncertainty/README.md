# Paired comparative uncertainty: manuscript Table 7

This retrospective analysis compares Stage-1 M1 minus M4 (MAE, RMSE and P99
absolute error) and CropAndWeed M1 minus M5 (crop IoU, MAE and RMSE). It uses
the fixed evaluated models and observed acquisition units.

## Reproduce

From the repository root, with Python >=3.9 and NumPy >=1.22:

```bash
python -B -m unittest discover -s scripts -p test_paired_uncertainty.py -v
python -B scripts/analyze_paired_uncertainty.py
```

The default reads this directory and writes to `reproduced/paired_uncertainty/`.
Use `--output-dir` to choose another output directory; `--compact-input-dir`
can select a copy of these inputs and their manifest. Reference reproduction
uses Python 3.12.14 and NumPy 2.3.5. It requires no raw imagery, checkpoints,
prediction maps, or private acquisition metadata.

## Resampling

- Both populations use **5,000 paired replicates**, root seed **20260924**.
  `SeedSequence(20260924).spawn(2)` supplies PCG64 streams with spawn keys
  `(0,)` for Stage 1 and `(1,)` for CropAndWeed.
- Stage 1 samples eight whole sequences with replacement. All evaluated
  images in a sampled sequence are carried together, including repeated copies.
  The existing sequence sizes are 57, 69, 56, 42, 59, 60, 56 and 30 images
  in lexicographic order; together they cover all 429 images.
- CropAndWeed samples 48 sessions with replacement, each containing one image.
  Both models receive identical sampled units in every replicate.
- MAE and RMSE are image-weighted; Stage-1 P99 uses linear interpolation.
  External crop IoU is recomputed from pooled TP/(TP+FP+FN), rather than
  averaging image IoUs. Intervals use the 2.5th and 97.5th percentiles of
  paired differences with linear interpolation.

The M4 Stage-1 MAE and M1 external crop-IoU advantages are separated under
these procedures. The other four intervals include zero; point-estimate
criterion winners remain unchanged. Observed maxima are descriptive and
have no bootstrap interval. These comparisons concern the fixed models
and observed units, not training variability or a population-independence claim.

## Files and provenance

| File | Content |
|---|---|
| `paired_inputs_stage1.csv` | Public image/sequence/frame IDs, denominators, reference fractions and M1/M4 signed errors |
| `paired_inputs_external.csv` | Public image/session IDs, denominators, reference fractions, M1/M5 errors and integer confusion counts |
| `paired_contrasts.csv` | Six full-precision contrasts, percentile limits, signs, units and resampling settings |
| `bootstrap_replicates.csv` | Stored 5,000 paired differences per metric/population and replicate image counts; also regenerated by the script |
| `analysis_manifest.json` | Public-source/input/output hashes, full-precision reference values, grouping, runtime and seed/stream information |
| `verification.json` | Recorded original checks and the public-copy reproduction/test checks |

The paired inputs, contrast summary and replicate CSV are unchanged copies
of the completed analysis. Stage-1 sequence/frame assignments match
`results/crop_fraction_records.csv`; cohort identities match the public split
files. Counts and errors derive from the existing Stage-1 and external
per-image records. Public packaging removes the original-project input loader
and internal build/audit records; metric and resampling calculations are unchanged.

Fractions are stored on a 0–1 scale. `paired_contrasts.csv` also stores
percentage-point conversions; manuscript Table 7 displays four decimals.
`scripts/reproduce_tables.py` exports that display as `table7_paired_uncertainty.csv`.
The M3-specific 2,000-resample intervals are separate saved results in Table 8.

The population-specific terms in `LICENSE-DATA` apply to these records.
No author-supplied timestamps/GPS, raw source images or annotations are included.
